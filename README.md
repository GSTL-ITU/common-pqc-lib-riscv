# Common PQC Libraries for RISC-V

This codebase contains vendor-independent, bare-metal C ports of NIST PQC algorithms targeted for RISC-V soft cores.

### 🟢 Current Status: Software Ready
All modules have completed initial porting, and bare-metal RTL simulation validation. 

### Target Algorithms
* **ML-KEM (Kyber):** 🟢 Software Ready
* **ML-DSA (Dilithium):** 🟢 Software Ready
* **SLH-DSA (Sphincs+):** 🟢 Software Ready
* **FN-DSA (Falcon):** 🟢 Software Ready
